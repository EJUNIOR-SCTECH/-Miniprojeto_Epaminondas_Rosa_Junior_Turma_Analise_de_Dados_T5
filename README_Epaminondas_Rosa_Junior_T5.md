## 🚀 Como Executar o Projeto

1. **Via VS Code / Jupyter:**
   - Certifique-se de que o arquivo `Base Varejo.csv` está salvo na mesma pasta do projeto.
   - Abra o arquivo `miniprojeto.ipynb` no VS Code ou Jupyter Notebook.
   - Clique em **"Run All"** (Rodar Tudo) ou execute as células em ordem sequencial de cima para baixo.
   - Ao executar a Célula 6, o arquivo `df_limpo.csv` será gerado automaticamente no seu diretório local.

2. **Via Google Colab:**
   - Faça o upload do arquivo `miniprojeto.ipynb` no Google Colab.
   - Envie a base de dados `Base Varejo.csv` para a sessão do Colab (ícone de pasta no menu lateral esquerdo).
   - Vá no menu superior em **Ambiente de Execução > Executar todas** (`Ctrl + F9`).
